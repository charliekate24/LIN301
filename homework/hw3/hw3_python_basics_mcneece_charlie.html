Part 2 — Lists, Dictionaries, and Sets: Cataloguing the Odyssey

Setup

In the Terminal, download Samuel Butler’s 1900 prose translation of the Odyssey from Project Gutenberg, saving it as odyssey.txt:

curl -o odyssey.txt https://www.gutenberg.org/cache/epub/1727/pg1727.txt

Then, in a Python code chunk in your .qmd, load it into a string:

with open("odyssey.txt", encoding="utf-8") as f:
    text = f.read()

New trick: .split(), called on a string with no arguments, breaks it into a list of words, splitting wherever there’s whitespace (spaces, tabs, line breaks):

words = text.split()

Lists

  1. Print len(words) — how many tokens are in the whole downloaded file?
  2. Use slicing to print the first 20 words: words[0:20]. Does this look like the actual poem, or something else?
  3. Try a few different slices, further into the list, until you find one that clearly looks like real Homer rather than Project Gutenberg’s own text. Record the slice (the indices) you used, and what it printed.

Sets

  1. Build unique_words = set(words). Print len(unique_words).
  2. Compute the type-token ratio for the whole file: len(unique_words) / len(words).
  3. On Day 14 in class, the two 23-word opening lines we analyzed had type-token ratios around 0.78 and 0.91. Compare those to the ratio you just got for the whole Odyssey. Is it higher or lower — and in 2–3 sentences, explain why you think that happens as a text gets longer.

Dictionaries

New trick: .find() works like the list .index() you already know from Day 12, but on a string — it returns the position where a match starts, or -1 if there isn’t one.

  1. Try text.count("Odysseus"). What do you get?
  2. Whatever number you got, don’t assume it means “Odysseus” is scattered evenly through the poem. Use position = text.find("Odysseus") to find where one match starts, then slice out text[position - 150 : position + 150] to read the sentence around it. Where does it actually turn up — in the middle of a book, or somewhere more limited, like the front matter? Once you’ve looked, use "Ulysses" in text to check which name Butler’s own narrative actually relies on, then find the count that works.
  3. Build a dictionary called character_counts that maps each of these names to how many times it appears in text, using the string method .count(): "Ulysses", "Penelope" (his wife), "Telemachus" (his son), and "Minerva" (the goddess who helps him — also a Roman name, standing in for the Greek Athena).
  4. Print character_counts.
  5. Using dictionary indexing (not just eyeballing the printed output), confirm which of the four names appears most often.
  6. Add one more key of your choice to character_counts — any word, name, or place you’re curious about — using its .count() in text.
